# GCX Editorial Visual QA

Use this checklist before publishing new editorial modules that mimic real-world collectibles, covers, cards, consoles, or products.

## Proportion Rules

- Trading-card placeholders must use `aspect-ratio: 63 / 88`.
- Video-game box art placeholders should match the target package shape when known.
- Console/product images should not overlap copy and must keep their focal object visible.
- Do not stretch official art into non-native shapes.

## Image Rights Rules

- Use original GCX editorial art, licensed images, approved press assets, or source/API images with terms that allow the intended use.
- If usage rights are not clear, use a GCX placeholder and link to the source page instead of copying the image.
- Do not hotlink card artwork from third-party collector pages as a long-term production strategy without confirming permission or terms.

## Required Checks

- Verify desktop and 390px mobile.
- Confirm no horizontal overflow.
- Confirm image/card modules preserve expected aspect ratio.
- Confirm source links render for image-pending entries.
- Confirm the page does not look like duplicated coverage because of repeated hero art.
